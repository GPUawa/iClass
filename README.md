## 致谢：

**开发工具与框架**

- [Electron](https://www.electronjs.org/zh): 跨平台桌面应用开发框架  
- [Vue 3](https://cn.vuejs.org/): 前端界面框架
- [Naive UI](https://www.naiveui.com/): 丰富的 Vue 3 组件
- [electron-vite](https://cn.electron-vite.org/): 项目构建工具
 
> 完整依赖列表参见项目根目录下 `package.json`

**资源与服务**

- [和风天气图标](https://dev.qweather.com/docs/resource/icons/): 天气图标显示
